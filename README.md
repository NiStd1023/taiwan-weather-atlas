# 台灣氣象觀測 Taiwan Weather Atlas

以中央氣象署開放資料為基礎的互動式天氣儀表板，透過台灣地圖查看縣市預報、鄉鎮逐時預報與測站觀測。

**線上使用：** [開啟氣象儀表板](https://nistd1023.github.io/taiwan-weather-atlas/)

## 功能特色

- 互動地圖：選擇縣市，切換預報最高溫與降雨機率。
- 今明 36 小時預報，以及全台概況與縣市比較。
- 鄉鎮逐時預報：氣溫、體感溫度、濕度曲線及 3 小時降雨機率。
- 各縣市測站觀測資訊、天氣警特報與近期有感地震報告。
- 常用地點收藏、預設縣市與鄉鎮，以及衛星雲圖和雷達回波圖連結。
- 支援 PWA 安裝；離線時顯示提示，無法更新氣象資料。

## 取得中央氣象署開放資料授權碼

1. 前往 [中央氣象署開放資料平臺](https://opendata.cwa.gov.tw/)，註冊或登入氣象會員。
2. 登入後，進入「會員資訊」→「API 授權碼」；也可從 [API 授權碼頁面](https://opendata.cwa.gov.tw/user/authkey)進入。
3. 點選「取得授權碼」，複製個人的完整授權碼。一般為 `CWA-` 開頭的一串代碼。
4. 流程與規範如有變動，請以 [氣象署常見問答](https://opendata.cwa.gov.tw/faq)及[開發指南](https://opendata.cwa.gov.tw/devManual/description)為準。

## 在網站設定授權碼

1. 開啟[氣象儀表板](https://nistd1023.github.io/taiwan-weather-atlas/)。
2. 點右上角「設定」，或展開「連線管理」並點「連接氣象資料」。
3. 貼上授權碼，按「連接資料」。連線成功後即可讀取氣象署資料；尚未設定時會標示為「示範資料」。
4. 更換或清除授權碼時，點「設定」重新輸入，或使用「清除授權碼」。

授權碼、收藏與預設地點儲存於目前瀏覽器的本機儲存空間。不同瀏覽器、裝置或網站網址可能需要重新設定；清除網站資料也會移除設定。網站會由瀏覽器直接向氣象署 API 發出包含授權碼的 HTTPS 請求，授權碼可能出現在瀏覽器開發者工具與網路紀錄中。請勿將授權碼提交至公開儲存庫、貼在截圖或分享給他人；共用裝置使用後可在設定中清除。

## 使用方式

- 在地圖或縣市選單選擇地區，查看縣市預報。
- 點「逐時預報」，選擇鄉鎮市區；圖表與降雨機率皆以該地代表點的預報為準。降雨機率依氣象署資料以 3 小時為一個時段。
- 在逐時預報面板中，可將選定地點加入「我的最愛」或設為預設。
- 點「觀測站數據」可查看所選縣市各測站的觀測時間及數值；觀測與預報的更新時間可能不同。
- 警特報與地震報告位於頁面下方，完整內容請以中央氣象署發布為準。地震報告為事後資訊，並非地震預警。

## PWA 安裝

在支援的瀏覽器開啟網站後，使用網址列或瀏覽器選單中的安裝功能。iPhone／iPad 可在 Safari 點選「分享」→「加入主畫面」。首次載入需連網；離線時不能更新天氣、警特報或地震資訊，實際安裝與離線體驗依裝置及瀏覽器而異。

## 資料來源

| 資料 | 資料集 |
| --- | --- |
| 今明 36 小時縣市預報 | F-C0032-001 |
| 鄉鎮逐時預報及 3 小時降雨機率 | F-D0047 系列（依縣市選擇） |
| 氣象測站觀測 | O-A0003-001、O-A0001-001 |
| 縣市天氣警特報 | W-C0033-001 |
| 顯著有感與小區域有感地震 | E-A0015-001、E-A0016-001 |

氣象資料來自[中央氣象署開放資料平臺](https://opendata.cwa.gov.tw/)，使用時請遵守其[使用規範](https://opendata.cwa.gov.tw/about/rules)。行政區圖資由內政部國土測繪中心提供，經 Geodata 轉製；離島以位置經調整的插圖呈現。圖資無法載入時，網站會顯示縣市示意圖。

## 開發與部署

本專案為靜態 HTML、CSS 與 JavaScript，入口為 `index.html`；服務工作執行緒與 PWA 設定分別位於 `sw.js` 和 `manifest.webmanifest`。本機開發可在專案目錄啟動靜態伺服器，例如 `python -m http.server 8000`，再開啟 `http://localhost:8000/`。PWA 安裝與離線功能需要安全環境（HTTPS 或 localhost）。

GitHub Pages 設定從 `main` 分支根目錄部署；提交至該分支後會觸發重新發布。原先的 Sites 版本是獨立部署，並不會與此儲存庫自動同步。

`site-history.bundle` 是先前 Sites 專案的 Git 歷史備份，並未合併進此儲存庫的主要提交歷史。
